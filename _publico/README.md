# Entornos de Desarrollo · 1.º DAW · Curso 2026/27

Material del módulo **Entornos de Desarrollo** (IES Doñana). Se actualiza a lo largo del curso.

## Contenido

| Carpeta | Qué hay |
|---|---|
| `00 - General` | Programación, calendario y presentación del módulo |
| `UD1 - Desarrollo del software` | Apuntes, presentación, sesiones y tareas |
| `UD2 - Instalacion y uso de entornos de desarrollo` | Apuntes, presentación, prácticas P2.x y manuales de GitHub |
| `UD3 - Diseno y realizacion de pruebas` | Apuntes y presentación |
| `UD4 - Optimizacion, documentacion y refactorizacion` | Apuntes y presentación |
| `UD5 - Elaboracion de diagramas de clases` | Apuntes y presentación |
| `UD6 - Elaboracion de diagramas de comportamiento` | Apuntes y presentación |

Cada documento está en PDF (para leer) y en Word (editable). Cada práctica tiene su carpeta con el enunciado y, si los hay, los ficheros de partida.

## Cómo descargarlo

- **Sin Git:** botón verde **Code → Download ZIP**.
- **Con Git** (recomendado, así solo descargas lo nuevo):

  ```
  git clone https://github.com/<usuario>/endes2627.git
  ```

  y cada día, dentro de la carpeta:

  ```
  git pull
  ```

Consulta el *Manual básico de GitHub* (UD2) si tienes dudas.
